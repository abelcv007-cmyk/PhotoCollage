# Capturas de pantalla

Capturas reales de PhotoCollage tomadas en el emulador de Android Studio (Medium Phone, API 37).

| Archivo | Contenido |
|---|---|
| `01_collage_vacio.png` | Estado inicial con el mensaje «Tu collage está vacío» |
| `02_varias_fotos.png` | Collage con cuatro fotos en dos columnas |
| `03_foto_seleccionada.png` | Una foto seleccionada con su borde y su marca |
| `04_filtros.png` | Gris aplicado a la foto 3 y sepia a la foto 4 |
| `05_ajustes.png` | Foto 1 girada, con brillo y saturación modificados |
| `06_texto.png` | Texto «Prueba» sobre la foto 3 |
| `07_tres_columnas.png` | Distribución del collage en 3 columnas |
| `08_eliminar_todo.png` | Diálogo de confirmación de «Eliminar todo» |
| `09_compartir.png` | Selector de aplicaciones al compartir el collage |
| `10_horizontal.png` | La app en horizontal, con el panel de controles a la derecha |
| `11_eliminar_foto.png` | Diálogo de confirmación al eliminar una foto |

Para capturar desde Android Studio: panel **Running Devices** → icono de cámara (*Take screenshot*).
